# Rallar Black Box Headless SPA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a separate `rallar-black-box-headless` SPA that runs on the Hetzner headless browser workers as a minimal recipe executor and run reporter, without loading the existing `rallar-black-box` operator UI.

**Architecture:** Extract the UI-free control-agent runtime, bootstrap parsing, browser-rallar bridge, and control WebSocket client into `packages/shared-test/rallar-bb-test`. Keep `apps/rallar-black-box` as the human operator console, and add `apps/rallar-black-box-headless` as a vanilla TypeScript/Vite app with a tiny DOM status surface. Publish the headless app under the same origin at `/headless/` so existing API/control CORS policy and TLS hostnames remain stable. Keep Chromium as the default Playwright browser engine, while allowing Hetzner runs to opt into Firefox or Playwright WebKit for diagnostic cross-engine evidence.

**Tech Stack:** TypeScript, Vite, vanilla DOM, `packages/shared-test/rallar-bb-test`, Playwright headless browser engines (`chromium` default, `firefox` and `webkit` selectable), Vitest, Hetzner controller shell scripts, GitHub Actions distributed recipe workflow.

---

Date: 2026-06-28

Status: Ready for implementation.

## Decision Summary

Build a new app at `apps/rallar-black-box-headless` instead of adding another route to the existing React SPA.

The new app must:

- Load in a real browser and use the same browser-native Rallar runtime as the current headless worker.
- Auto-bootstrap from URL parameters generated by `apps/rallar-black-box/src/headless-worker-config.ts`.
- Connect to the control server WebSocket.
- Execute remote recipe commands.
- Stream heartbeats, stats, events, results, and terminal reports.
- Render only a tiny local/debug status page with basic agent information.
- Exclude React, React DOM, Sigma, graphology, topology UI, artifact browser UI, fleet UI, distributed-run history UI, run-manager UI, and operator REST polling helpers.
- Run under the selected Playwright browser engine when launched on Hetzner, with `chromium` as the default and `firefox`/`webkit` available as explicit diagnostic choices.

The existing operator SPA remains the human UI and can still launch old-style local workbench pages during rollback.

`webkit` means Playwright's patched WebKit build. It is useful Safari-family coverage, but it is not the branded Apple Safari binary, and Linux WebKit evidence must not be described as exact Safari certification.

## Non-Goals

- Do not change the distributed recipe protocol.
- Do not remove the existing `rallar-black-box` operator app.
- Do not create a second implementation of command execution or report streaming.
- Do not use React in `rallar-black-box-headless`.
- Do not deploy the headless app on a separate origin unless same-origin `/headless/` is blocked by production evidence.
- Do not make the headless browser fetch distributed-run history, fleet reports, artifacts, or run-manager snapshots.
- Do not make Firefox or WebKit part of the default required run matrix until Chromium health and RTC smoke are stable on the new headless SPA.
- Do not claim Linux Playwright WebKit is equivalent to Safari-on-macOS; it is a cross-engine compatibility signal only.

## Acceptance Criteria

- `npm --workspace rallar-black-box-headless run build` succeeds.
- The headless bundle boundary test proves the headless app does not include React, React DOM, Sigma, graphology, `App.tsx`, `control-run-manager.ts`, `distributed-recipes.ts`, `rtc-diagnostics.ts`, `topology-graph.ts`, `flow-builder.ts`, or `schema-authoring.ts`.
- The rendered smoke script proves `/headless/` shows the minimal status DOM at desktop and mobile viewports, logs no console errors, and does not request operator polling endpoints.
- `createHeadlessWorkerAgentUrl` defaults to the old operator SPA route during the first implementation pass and supports `RALLAR_BLACK_BOX_HEADLESS_ENTRY=headless`.
- With `RALLAR_BLACK_BOX_HEADLESS_ENTRY=headless`, generated URLs point at `/headless/` and keep the same control/runtime URL parameters.
- With no browser-engine override, Hetzner workers launch Playwright Chromium and report `fleetBrowserName=chromium`.
- With `RALLAR_BLACK_BOX_BROWSER_ENGINE=firefox` or `webkit`, Hetzner workers launch that Playwright engine and report the selected engine in worker logs, fleet metadata, workflow input, and artifact analysis context.
- The worker readiness check still uses `/runs/{runId}` as the authoritative readiness signal.
- The headless app status DOM is only informational and local-debug friendly.
- Hetzner deploy and rollout publish `/headless/index.html` and `/headless/assets/*`.
- `scripts/hetzner/dispatch-distributed-recipe.sh --headless-entry headless` forwards `headless_entry=headless` to the workflow.
- `scripts/hetzner/dispatch-distributed-recipe.sh --browser-engine firefox|webkit` forwards `browser_engine` to the workflow and worker env.
- The existing `rallar-black-box` operator build still succeeds.
- Chromium local two-agent health and RTC smoke distributed recipes pass before switching the default to `headless`.
- Firefox and WebKit health runs are diagnostic cross-engine checks; RTC smoke on those engines is evidence to record before making cross-engine parity a release gate.

function bundleHeadlessEntry(): Readonly<{
    brotliKiB: number;
    metafile: EsbuildMetafile;
}> {
    mkdirSync(outputDir, { recursive: true });
    const outputPath = path.join(outputDir, 'headless-agent.boundary.min.js');
    const metafilePath = `${outputPath}.meta.json`;

    execFileSync(
        esbuildBin,
        [
            'apps/rallar-black-box-headless/src/main.ts',
            '--bundle',
            '--minify',
            '--format=esm',
            '--platform=browser',
            '--target=es2023',
            '--tsconfig=apps/rallar-black-box-headless/tsconfig.json',
            `--outfile=${outputPath}`,
            `--metafile=${metafilePath}`,
        ],
        {
            cwd: repoRoot,
            stdio: ['ignore', 'ignore', 'pipe'],
        },
    );

    const bytes = readFileSync(outputPath);
    const brotliBytes = brotliCompressSync(bytes, {
        params: {
            [constants.BROTLI_PARAM_QUALITY]: 11,
        },
    }).length;

    return {
        brotliKiB: brotliBytes / 1024,
        metafile: JSON.parse(readFileSync(metafilePath, 'utf8')) as EsbuildMetafile,
    };
}

import type { RallarBlackBoxBrowserControlAgentSnapshot } from '@shared-test/rallar-bb-test/browser-control-agent.ts';

function text(value: unknown): string {
    return value === undefined || value === null || value === '' ? '-' : String(value);
}

function appendText(
    parent: HTMLElement,
    tagName: 'h1' | 'p',
    value: unknown,
    attr?: string,
): HTMLElement {
    const element = document.createElement(tagName);
    element.textContent = text(value);
    if (attr) {
        element.setAttribute(attr, '');
    }
    parent.append(element);
    return element;
}

function appendRow(
    list: HTMLDListElement,
    label: string,
    value: unknown,
    attr: string,
): void {
    const term = document.createElement('dt');
    term.textContent = label;

    const details = document.createElement('dd');
    details.textContent = text(value);
    details.setAttribute(attr, '');

    list.append(term, details);
}

export function renderHeadlessStatus(
    root: HTMLElement,
    snapshot: RallarBlackBoxBrowserControlAgentSnapshot,
): void {
    const latestCommand = snapshot.state.commandHistory.at(-1);
    const latestEvent = snapshot.state.events.at(-1);

    root.replaceChildren();

    const section = document.createElement('section');
    section.className = 'agent-shell';
    section.setAttribute('aria-label', 'Headless agent status');

    const header = document.createElement('header');
    appendText(header, 'h1', 'Rallar Black Box Headless Agent');
    appendText(header, 'p', snapshot.lastAction, 'data-last-action');
    section.append(header);

    if (snapshot.lastError) {
        const error = appendText(section, 'p', snapshot.lastError, 'data-last-error');
        error.className = 'error';
    }

    const list = document.createElement('dl');
    appendRow(list, 'Agent', snapshot.bootstrap.agentId, 'data-agent-id');
    appendRow(list, 'Run', snapshot.bootstrap.runId, 'data-run-id');
    appendRow(list, 'Control', snapshot.control.state, 'data-control-state');
    appendRow(list, 'Runtime', snapshot.state.status, 'data-runtime-state');
    appendRow(list, 'Provider', snapshot.bootstrap.providerMode, 'data-provider');
    appendRow(list, 'Transport', snapshot.bootstrap.transport, 'data-transport');
    appendRow(list, 'Room', snapshot.bootstrap.roomId, 'data-room-id');
    appendRow(list, 'Sent', snapshot.control.sentCount, 'data-sent-count');
    appendRow(list, 'Received', snapshot.control.receivedCount, 'data-received-count');
    appendRow(list, 'Latest command', latestCommand?.commandId, 'data-latest-command-id');
    appendRow(list, 'Latest event', latestEvent?.topic, 'data-latest-event-topic');
