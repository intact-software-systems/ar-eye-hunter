# Extend a live room session

## Product decision

A facilitator can grant one extra minute while the session is active. Polls run on calendar time. Grumpy Town advances on simulation ticks, including after director recovery. Preserve each authority's time model and reuse the existing Rallar deadline and checkpoint mechanisms. Consider a shared SDK abstraction when the two consumers repeat an actual contract.

## Slice 1 — poll schedule revision

An authorized host can extend an open poll by 60 seconds once. A revision precondition protects against duplicate delivery and stale writes. Keep accepted ballots and terminal closure. Include the revision in authoritative snapshots, refresh visible views at a bounded cadence, and update both the phase and the displayed cutoff. A delayed older snapshot cannot roll the schedule back. Prove permission, replay, boundary, and spectator recovery across the original cutoff through a browser journey.

## Slice 2 — Grumpy Town on #832

The active director can grant one extra minute of simulated play per live match. Preserve scores, seats and elapsed ticks. Publish through the existing checkpoint flow and show the committed remaining time on all participants. A replacement director inherits the consumed extension. Keep original three-minute checkpoints readable. Test the button, peer convergence, repeat attempts, terminal state and checkpoint validation. Stack #832 on this branch so the game can be reviewed independently.

## Delivery

The parent targets main. The child targets the parent until the parent merges. Run focused authority, browser, game and type checks, then review both diffs. Durable scheduling, automatic empty-room effects and a new public timeline API are future product decisions.
