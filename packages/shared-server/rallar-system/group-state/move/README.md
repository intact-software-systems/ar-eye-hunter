# Move together ownership and navigation

Move together admits a consenting cohort to one destination atomically. Browser
arrival follows separately. Source memberships and governance are retained.
There is one current schema, no migration reader, and no game-specific policy in Rallar.

| Flow                     | Entry and decision owner                                                                                                                                                                                                                                                                                                                                                              | Exit and failure                                                                                                                                                                                                                |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Authenticated HTTP       | [registerGroupMoveRoutes](../../../../../apps/api-v1/src/group-state/register-group-move-routes.ts) validates route scope and admission quota; [group-move-command.ts](group-move-command.ts) validates exact command and captured authority.                                                                                                                                         | [submitGroupMove](group-move-inbox.ts) reserves the logical request in AppInbox. Reused request identity with changed command is a conflict.                                                                                    |
| Consent and commit       | [GroupMoveService](group-move-service.ts) reads current proposal, claims, auth sessions, source presence and destination admission; [computeGroupMove](compute-group-move.ts) pins the cohort, consent and deadline.                                                                                                                                                                  | A changed cohort, revoked authority, expired deadline or destination denial prevents admission. Terminal decisions are durable and recoverable.                                                                                 |
| All-or-none membership   | [computeGroupCohortAdmission](../mutation/membership/compute-group-cohort-admission.ts) stages ordinary joins against preceding results, counting distinct principals and selected sessions. [computeGroupMoveAdmission](compute-group-move-admission.ts) translates its failures to the Move together response contract.                                                             | The service validates and writes authority guards, move storage, every membership write and outbox entries in one AppInbox transaction. A compare-and-set failure rolls back everything and QueueBox retries from a fresh read. |
| Storage and races        | [GroupMoveRepository](group-move-repository.ts) owns exact scoped records and live source/principal claims; [computeGroupMoveSource](compute-group-move-source.ts) fences membership, presence and admission rows.                                                                                                                                                                    | No inner retry or domain lock. Missing/corrupt records fail closed; a claim prevents overlapping live moves for one principal. Terminal claims no longer block another proposal.                                                |
| Notifications and expiry | [computeGroupMovePublication](group-move-outbox.ts) prepares principal-scoped WebSocket wakeups with provenance and durable deadline work. [installGroupMoveDeadline](group-move-inbox.ts) enqueues expiry through AppInbox.                                                                                                                                                          | Messages carry only scoped identity. Reads supply the decision. Retry scheduling does not change deadline identity; stale expiry loses against cancellation or commit.                                                          |
| Browser recovery         | [RallarRoomMove](../../../../shared-web/browser/rooms/move/rallar-room-move.ts) subscribes to authenticated session changes and wakeups, coalesces reads, and retries explicit destination entry.                                                                                                                                                                                     | Session replacement fences obsolete callbacks. A committed decision survives missing notifications, lost responses and local storage loss. Old decisions do not pull a browser back from another room.                          |
| Session activation       | [activateGroupMove](../../../../shared-web/browser/rooms/join-room.ts) connects a fresh destination presence generation, waits for its authoritative summary, disconnects only this source session and adopts destination state.                                                                                                                                                      | Failure leaves a visible entry retry. Arrival is acknowledged only after activation; no source membership removal is sent. Arrival updates refresh retained-room rosters.                                                       |
| Game and UI              | [RoomMovePanel](../../../../shared-react/room-move-panel.tsx) renders consent and Present/Away. [AR Eye](../../../../../apps/ar-eye-hunter-v1/src/arena-ui/arena-room-move.tsx) blocks active-match departure; [Relic browser composition](../../../../../apps/relic-hunters-v1/src/game/relic-hunters-browser.ts) reuses its participation lock and authoritative eligibility check. | The organizer gains no director/Keeper authority. Relic destination participation requires its explicit Join control. Spectators are excluded from the moving cohort.                                                           |

The public [contract](../../../../shared/api/mutation/group-move.ts) and
[decoder](../../../../shared/api/mutation/decode-group-move.ts) bound a cohort to
16 player sessions and consent to two minutes. Browser-safe exact-object decoding
is shared with server protocol decoders through a direct import.

Tests mirror `group-state/move` for pure computation and SQL rollback, `group-state/inbox`
for replay, `shared-web/rooms/move` for browser recovery, and
`tests/playwright/*/move-together` for the human-click journeys. The API black-box
recipe is `packages/shared-test/black-box-runner/tests/api-v1/api-v1-group-move.json`.
